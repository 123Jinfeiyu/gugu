# DESIGN.md —《食物在身体里的旅行》课堂课件

## 一、定位

- 用途：教科版科学四年级上册 第二单元第 5 课，1 课时（40 分钟）现场授课投屏
- 受众：四年级学生（主）+ 听课教师（次），教室大屏 / 希沃白板播放
- 页数：16 页；风格：教育暖橙（#EA580C 系），与"咕咕"智能体界面同色
- 输出要求：可整份导入希沃白板，因此**不用动画、不用外链图片、文字全部为可编辑文本**

## 二、画布与安全区

- 1280 × 720，padding 上下 60 / 左右 60，内容区 1160 × 600
- 页脚：仅内容页有，右下角页码 `NN / 16`，y=670，14px，颜色 #A89684
- 封面 / 结束页不加页脚

## 三、配色

| 槽位 | Hex | 用途 |
| --- | --- | --- |
| 主色 | `#EA580C` | 站标签、编号、标题强调、路线主线 |
| 深主色 | `#9A3412` | 大字标题、关键动词 |
| 浅主色 | `#FFEDD5` / `#FFF7ED` | 提示卡底、图片来源底 |
| 强调色 | `#1F8A6B` | 数据数字、"咕咕说"对话（全篇唯一高饱和强调色） |
| 正文 | `#241C17` | 主文字 |
| 次要 | `#7C6A5C` | 说明、注释 |
| 线 | `#EFDCCA` | 1px 分区线 / 标题下贯通线 |
| 页面底 | `#FFFBF6` | 画布背景 |

面积纪律：橙系 ≤60%，米白 ≤30%，绿 ≤10%。不用阴影，层次靠底色 + 1px 线 + 留白。

## 四、字体与字号

- 中文：微软雅黑（`Microsoft YaHei`）；西文跟随，不单独换字体
- 封面主标 72 / 副标 26 / 说明 18 / 信息 15
- 页面主标 36 / 卡片小标 24 / 正文 20 / 注释 15 / 页脚 14
- 巨型数字 96-120（仅 P11、P14 使用）；层级跳跃 ≥ 4px，一页样式组合 ≤ 4 种

## 五、视觉母题（全篇复用）

1. **左上胶囊**：`第 1 站` / `活动二` / `导入`——橙色细边框胶囊 + 15px 橙字，位置固定 (x=60, y=60)
2. **主标下 1px 贯通线**：贴主标底线，横贯 1160，色 `#EFDCCA`
3. **右下页码**：`04 / 16`
4. **"咕咕说"块**：浅绿底（`#F1FAF6`）+ 左侧 3px 绿竖条 + 15px 灰字标签，用于每站一句对话示例——全篇同一形态
