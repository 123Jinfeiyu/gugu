# 咕咕 · 消化小导游

一个面向**小学科学教科版四年级上册《食物在身体里的旅行》**的 AI 教学智能体，按蜀山区第二届"AI 智能体应用高手"评选**赛道一（教学创新赛道）**的评审口径设计：聚焦备授课教学全流程，把智能体嵌进"备课—课中互动—课后评价"三个真实环节。

卡通形象与五站插图全部取自同课课件：《食物在身体里的旅行》里的拟人小胃、口腔、食道剖面、胃剖面、肠道角色与整条消化道时间轴，保证课堂上的形象统一。

---

## 一、怎么跑起来

**方式一（推荐，给上课用）**
双击 `启动.bat` → 浏览器自动打开 <http://localhost:8787>。
关掉那个黑色窗口，服务就停了。

**方式二（开发者）**
```bash
cd gugu
node server.js          # 端口可用环境变量 PORT 改
```

> 需要 Node.js 18 以上（本机 v22）。没有任何 npm 依赖，不用装包也能跑。

## 二、四个模式怎么用

### 1. 课堂（学生端 / 大屏）
- 左边是对话区，咕咕带着孩子一站一站漂；右边是**五站地图**，走完一站点亮一枚徽章。
- 每一站都有一张"探索卡"：本站的比喻（粉碎车间 / 滑滑梯 / 搅拌工厂 / 吸收主战场 / 水分回收站）+ 器官插图 + 闯关题。
- 咕咕的回答被刻意限制在 **80 字以内**，并且**先给线索、先反问**，孩子追问或答错两次才讲透——这是为了守住"让学生自己想出来"，也是赛道一"对学生学习效果实际提升"最容易在视频里被看见的点。
- 右上角喇叭可以把回答读出来（教室里外放很稳，中文 TTS）。

### 2. 实验室（食道蠕动模拟）
一条滑块控制食团位置：往下推一格，管壁就收一圈，收缩波跟着食团走；右侧"食团位置 / 管壁状态 / 已用时间"三个数字实时在变。
可以开"自动蠕动"，把频率从 5 次/分拉到 9 次/分，看它自己一节一节把食物送进胃。
右侧三个任务对应三个课堂动作，做完自动打勾；最后一句"带着发现去问咕咕"会直接把这站的追问发过去。
这个模块替代的是原本要准备软管和馒头、还得一组一组轮流做的那个实验。

### 3. 备课台（教师端）
填课题、学段、学科、课时、学情、额外要求 → 点「生成教学设计」。
输出固定六段：**学习目标 / 教学重难点 / 教学流程（表格）/ 问题链 / 板书设计 / 评价量规**，逐字流式输出，可复制、可下载 `.md`。
「生成课后任务单」按基础关 / 闯关关 / 动手关 / 家长一句话四段出。

### 4. 学情（教师端）
左边是报告（先给一份本地数据小结，点「生成分析报告」再让模型写深度的），右边是真实统计：提问总数、闯关次数、通关站次、整体正确率、逐站正确率、最近学生提问原话。
报告要求模型**引用数据和学生原话**，不许空话——评审看的就是"是不是真的在这节课上用过"。

## 三、数据与密钥

| 文件 | 作用 |
|---|---|
| `secret.json` | DeepSeek 密钥，**只在服务端读取，不会被浏览器下载到**（`/secret.json` 返回 404）。也可以改用环境变量 `DEEPSEEK_API_KEY`。 |
| `data/events.jsonl` | 课堂事件流水（提问、闯关对错），学情页从这里统计。删掉这个文件 = 清空本节课数据。 |
| `tools/seed-demo.js` | 灌一份"一节课"的演示数据（50 次提问、40 次闯关），录视频前想要真实感的数据就跑它。 |
| `public/` | 前端与素材，服务端只对外提供这个目录。 |

> ⚠️ 这个 key 一旦贴到公开仓库/网盘就会泄露，交材料前把 `secret.json` 从压缩包里排除，或者临时换成新 key。

## 四、换成别的课

1. `public/app.js` 顶部的 `STATIONS` 数组：改站点名、比喻、描述、插图、快捷问题、闯关题。
2. 服务端 `server.js` 里的 `GUGU_PERSONA`：改角色设定与知识边界（现在是五个消化器官 + 消化健康）。
3. `public/app.js` 的 `paintLab()` 与 `index.html` 里的 `#labSvg`：改模拟实验（现在是食道蠕动，改回呼吸/电路同理）。
4. 把新课件里的插图导成 webp 放进 `public/assets/`。

## 五、交付材料

`交付材料/` 里是照着 05 号选手那种五段式结构写好的：

| 文件 | 内容 |
|---|---|
| `01-演示视频逐字稿.md` | 7 分钟完整口播稿，带时间轴、镜头提示、录制前检查清单 |
| `02-申报表填写参考.md` | 附件 1 每一栏怎么填、200 字案例简介、材料清单、评委三问 |

## 六、录 5–8 分钟演示视频的分镜建议

政策要求：MP4、5–8 分钟、统一 3 秒片头（蓝底白字，案例名称 / 单位 / 姓名）、片尾"合肥市蜀山区教育体育局 + 年月"。

| 时间 | 画面 | 说的话（要点） |
|---|---|---|
| 0:00–0:20 | 片头模板（3 秒）+ 课件第 1 页"微型潜航器已启动" | 一句话交代痛点：消化器官在身体里看不见，蠕动更是看不见，孩子只会背名称。 |
| 0:20–1:10 | 备课台，输入学情，点生成 | 强调"备课从 40 分钟压到 5 分钟"，念两条问题链，说明它按课标六段出。 |
| 1:10–1:30 | 下载的 .md 在 Word 里打开 | 证明成果可编辑、能进教案本。 |
| 1:30–3:30 | 课堂：学生问"馒头嚼久了为什么会变甜" | 重点剪**咕咕反问**而不是直接给答案，再剪孩子自己说出"唾液把淀粉分解了"。 |
| 3:30–4:40 | 第 2 站闯关，故意答错一次 | 展示错误反馈与再试，徽章点亮、进度条走。 |
| 4:40–5:40 | 实验室：推滑块 → 自动蠕动 | 讲"动态模拟替代了要准备软管的演示实验"，一次吞咽 8 秒。 |
| 5:40–6:40 | 学情页，点生成报告 | 念"食道、胃正确率 63%，共性误区是把食道当成食物自己滑下去的通道"，说明下节课怎么补。 |
| 6:40–7:20 | 学生用一句话讲路线 / 前后测对比 | 落"学习效果的实际提升"。 |
| 7:20–7:40 | 片尾模板 | 收束：一个智能体、三个环节、一条可复制的路径。 |

录屏建议 1920×1080，浏览器缩放 100%，提前把 `data/events.jsonl` 清掉再跑一遍真实操作（或跑 `node tools/seed-demo.js`），视频里的数据才对得上。
